
# Tutorial 52 — Figma Basics

## 1. What is Figma?
Figma is a design tool used to create website layouts,
mobile app interfaces, and UI/UX prototypes.

## 2. Important Terms

### Frame
A container representing a webpage or screen.

### Shapes
Rectangles, circles, and other shapes used to create UI elements.

### Text
Used for headings, paragraphs, labels, and buttons.

### Layers
Used to organize and select individual design elements.

### Components
Reusable design elements, such as buttons and navigation bars.
