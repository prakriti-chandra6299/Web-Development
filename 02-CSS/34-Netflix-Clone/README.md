# Netflix Clone 🎬

A Netflix-inspired streaming homepage built using HTML5 and CSS3 as part of my web development learning journey.

## Features

- Dark cinematic hero section
- Email input form UI
- Movie poster gallery
- Trending Now section
- Feature cards with hover effects
- Expandable FAQ section
- Responsive layout for desktop, tablet, and mobile
- Styled footer with placeholder links

## Technologies Used

- HTML5
- CSS3
- CSS Grid
- Flexbox
- Media Queries
- CSS Transitions and Gradients

## How to Run

1. Download or clone this project.
2. Open `index.html` in a web browser.
3. Enjoy exploring the page.

## Note

This is an educational UI project, not a functional Netflix service. It does not provide real accounts, subscriptions, or streaming.

Created for learning purposes.
